# PKL Output Documentation: `all_results.pkl`

Generated by `run_analysis.py` from CSV data. A pickled nested dictionary with all analysis results for every dataset in the run.

> **Tip**: After each run, open `analysis_results/log_output.md` for an auto-generated field guide that reflects the exact keys, DataFrame shapes, and columns produced by _that specific run_ (including any user_metrics columns). This static document describes the pkl in general.

---

## MATLAB Reference - Deprecated (Not provided in this release)

This Python implementation is a port of the original MATLAB `PAM_MetricAnalysisCombined.m` from the BioSEL lab M.S. Thesis.

**Structural Equivalence:**

- MATLAB: `IO_results.dataset_name.FieldName = value`
- Python: `io_results["dataset_name"]["FieldName"] = value`

All field names match the original MATLAB struct fields. `pd.DataFrame` replaces MATLAB tables, `np.ndarray` replaces MATLAB arrays.

> Note: if there is an interest in wanting the original MATLAB code, create a git issue on the hosting GitHub repo or contact the authors. It is maintained by the authors that the Python port, the BioSEL-PULSE is a more powerful tool and the successor to the MATLAB codes that was only for M.S. Thesis. See `02_LIMITATIONS.md` for more information.

## Quick Start

```python
import pickle

# Load the pickle file
with open("analysis_results/all_results.pkl", "rb") as f:
    io_results = pickle.load(f)

# List all datasets
datasets = [k for k in io_results if not k.startswith("_")]

# Access one dataset
ds = io_results[datasets[0]]

# Key scalar metrics
ds["LoopMean"]                        # mean hysteresis loop area
ds["NormLoopValue"]                   # normalized (dimensionless)
ds["ellipse_result"]["area"]          # centroid ellipse area
ds["ellipse_result"]["eccentricity"]

# Core DataFrames
full_df   = ds["FullDat"]    # complete time-window signal
active_df = ds["activeDat"]  # pressurization window only (primary analysis data)
```

---

## Top-Level Structure

```
io_results = {
    "dataset_1_name": { ... full results dict ... },
    "dataset_2_name": { ... full results dict ... },
    ...
}
```

Keys starting with `_` (e.g., `_failures`, `_warnings`) are pipeline metadata; they are stripped before pickling and do not appear in the saved file.

## MATLAB→Python Key Mapping

| MATLAB Function                           | Output                                  | Python Key(s)                                                             |
| ----------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------- |
| `cycle_snapshots()`                       | Filtered cycles                         | `FullDat`                                                                 |
| `cycle_active_loop()`                     | Active window data                      | `activeDat`                                                               |
| `combinedscript_polyarea_normalization()` | Per-cycle areas, summary, normalization | `LoopArea_results`, `LoopArea_summary`, `LoopArea_norman`                 |
| ↳ Summary fields                          | Mean, std, min, max, median             | `LoopMean`, `LoopSTD`, `NormLoopValue`                                    |

| ↳ Regression residuals                    | Standard deviation of residuals         | `sigma_resid`                                                             |

| `hartigansDipAnalysis()`                  | Dip test on correlation distributions   | `dip_results` (DataFrame)                                                 |
| `avgHystLoop()`                           | Mean hysteresis trajectory              | `avgHystLoopTraj` (DataFrame)                                             |

## Per-Dataset Results Dictionary

### Metadata & Source Information

#### `_source` (str)

Source path showing folder hierarchy or origin of the dataset.

- **Example**: `"SubfolderA/SubfolderB/MyDataset"`, `"ExperimentGroup/Trial01"`
- **Use**: Track provenance (which folder each dataset came from).

---

### Raw Data (DataFrames)

#### `FullDat` (pd.DataFrame)

Columns: `Time_s`, `Pressure`, `Contraction`, `Cycle`

Full time-window dataset with all cycles selected by `step_count`. Contains the complete pressurization + depressurization signal before active-loop extraction. Use this when you need the idle baseline regions or full cycle shape.

```python
full_df = ds["FullDat"]
cycle_10 = full_df[full_df["Cycle"] == 10]
```

#### `activeDat` (pd.DataFrame)

Columns: `Time_s`, `Pressure`, `Contraction`, `Cycle` (+ optional derived/user columns)

Extracted active-pressurization windows. This is the primary analysis DataFrame; all core metrics (loop area, centroid, correlation) are computed from this. Any columns added by `derived_metrics` or `user_metrics.py` appear here.

```python
active_df = ds["activeDat"]
mean_pressure = active_df["Pressure"].mean()
```

Optional columns added when enabled:

| Column                     | Source          | Description                                               |
| -------------------------- | --------------- | --------------------------------------------------------- |
| `Setpoint`                 | derived_metrics | 0/1 binary step input derived from cycle 1 pressure edges |
| `Pressure_filt`            | derived_metrics | Smoothed pressure signal                                  |
| `Contraction_filt`         | derived_metrics | Smoothed contraction signal                               |
| `Velocity_Contraction`     | derived_metrics | dContraction/dt                                           |
| `Velocity_Pressure`        | derived_metrics | dPressure/dt                                              |
| `Acceleration_Contraction` | derived_metrics | d²Contraction/dt²                                         |

---

### Loop Area Analysis

#### `LoopArea_results` (pd.DataFrame)

Columns: `Cycle`, `LoopArea`, `PeakPressure`, `RestingX`, `PeakX`

Per-cycle hysteresis loop metrics:

- `LoopArea`: Area enclosed by pressure-contraction loop (shoelace formula)
- `PeakPressure`: 95th percentile pressure in that cycle
- `RestingX`: 5th percentile contraction (resting state)
- `PeakX`: 95th percentile contraction (fully activated)

```python
loop_areas = ds["LoopArea_results"]
areas_array = loop_areas["LoopArea"].values
```

#### `LoopArea_summary` (pd.DataFrame)

Columns: `LoopArea_mean`, `LoopArea_std`, `LoopArea_min`, `LoopArea_max`, `LoopArea_median`

Single-row summary of loop area statistics across all cycles.

```python
loop_mean = ds["LoopArea_summary"]["LoopArea_mean"].iloc[0]
```

#### `LoopArea_norman` (pd.DataFrame)

Columns: `PressureNormalizeDelta`, `xNormalizeDelta`, `comDen`

Normalization denominators used to compute `NormLoopValue`. `comDen` is the divisor.

#### `LoopMean` (float)

Mean hysteresis loop area across all analyzed cycles.

```python
mean_area = ds["LoopMean"]
```

#### `LoopSTD` (float)

Standard deviation of loop area (Bessel correction: `ddof=1`).

#### `NormLoopValue` (float)

Dimensionless normalized loop area (`LoopMean / comDen`). Use for comparing devices with different pressure/contraction ranges.

---

### Centroid Drift Analysis

#### `CentroidDrift_results` (pd.DataFrame)

Columns: `Cycle`, `Centroid_Pressure`, `Centroid_Pot`

Per-cycle centroid (mean pressure, mean contraction) of the hysteresis loop. Mahalanobis outlier cycles are interpolated before storage; raw outlier indices are in `CentroidDrift_outlier`.

```python
centroids = ds["CentroidDrift_results"]
pressure_centroids = centroids["Centroid_Pressure"].values
```

#### `CentroidDrift_summary` (list of 2 dicts)

List with exactly 2 elements:

- `[0]`: Pressure centroid statistics (keys: `mean`, `std`, `min`, `max`, `median`)
- `[1]`: Contraction centroid statistics (same keys)

```python
pressure_stats = ds["CentroidDrift_summary"][0]
pressure_mean  = pressure_stats["mean"]
pot_stats      = ds["CentroidDrift_summary"][1]
pot_std        = pot_stats["std"]
```

#### `CentroidDrift_outlier` (np.ndarray)

1D integer array of cycle indices flagged as Mahalanobis outliers. Points with Mahalanobis distance > chi2(df=2, p=0.997) threshold.

```python
outliers = ds["CentroidDrift_outlier"]
if len(outliers) > 0:
    print(f"Outlier cycles: {outliers}")
```

---

### Centroid Ellipse Metrics

#### `ellipse_result` (dict)

95% confidence ellipse fitted to the centroid cloud.

Keys:

- `area` (float): Ellipse area (π × a × b). `NaN` for degenerate/short datasets.
- `mu` (np.ndarray): `[mean_pressure, mean_contraction]`, the ellipse center
- `axes` (np.ndarray): `[minor_axis, major_axis]` lengths (ascending eigenvalue order from `np.linalg.eigh`; use `max()`/`min()` rather than position if you need a specific axis. `eccentricity` already does this internally.)
- `eccentricity` (float): 0 = circle, approaches 1 = line
- `ellipse_coords` (np.ndarray): 200 points forming the ellipse boundary (for plotting)
- `eigVec` (np.ndarray): 2×2 eigenvector matrix (principal component directions)
- `eigVal` (np.ndarray): Eigenvalues (variance along principal axes)

```python
ellipse = ds["ellipse_result"]
area    = ellipse["area"]
center  = ellipse["mu"]
coords  = ellipse["ellipse_coords"]  # shape (200, 2), for plotting

import matplotlib.pyplot as plt
plt.plot(coords[:, 0], coords[:, 1], 'b-')
plt.plot(center[0], center[1], 'ro')
plt.show()
```

### Linear Regression on Centroid

#### `mdl_fit` (sklearn.linear_model.LinearRegression or None)

Linear model predicting `Centroid_Pot` from `Centroid_Pressure`. Formula: `Contraction = slope × Pressure + intercept`. `None` if fewer than 2 valid centroid points after outlier removal.

```python
model = ds["mdl_fit"]
if model is not None:
    slope     = model.coef_[0]
    intercept = model.intercept_
    predicted = model.predict([[mean_pressure]])[0]
```

#### `sigma_resid` (float)

Standard deviation of residuals from the linear fit. `NaN` when `mdl_fit` is `None`.

### Cycle-to-Cycle Correlation

#### `cyc2cyc_results` (pd.DataFrame)

Columns: `Domain`, `Xcol`, `Ycol`, `MeanCorr`, `StdCorr`, `ValidPairs`, `TotalPairs`, `AllCorrVals`

Pearson correlation between consecutive cycles across 3 domains (3 rows):

| Row | Domain          | What it measures                    |
| --- | --------------- | ----------------------------------- |
| 0   | `"Input-Time"`  | Pressure vs Time correlation        |
| 1   | `"Output-Time"` | Contraction vs Time correlation     |
| 2   | `"Hysteresis"`  | Contraction vs Pressure correlation |

- `MeanCorr`: Mean Pearson r across valid consecutive pairs
- `StdCorr`: Standard deviation of r (Bessel correction)
- `ValidPairs`: Pairs that passed overlap threshold (`min_overlap=0.90`)
- `TotalPairs`: Total possible consecutive pairs (n_cycles − 1)
- `AllCorrVals`: List of all individual correlation values

```python
cyc2cyc = ds["cyc2cyc_results"]
hyst = cyc2cyc[cyc2cyc["Domain"] == "Hysteresis"]
hyst_mean = hyst["MeanCorr"].iloc[0]
hyst_std  = hyst["StdCorr"].iloc[0]
valid     = hyst["ValidPairs"].iloc[0]
```

---

### Hartigan's Dip Test (Unimodality)

#### `dip_results` (pd.DataFrame)

Columns: `Domain`, `DipStat`, `p_value`, `Significant`, `ModalLow`, `ModalHigh`

Tests whether each correlation distribution is unimodal or multimodal. Same 3-row structure as `cyc2cyc_results`.

- `DipStat` (float): Dip statistic (0 = perfectly unimodal)
- `p_value` (float): Bootstrap significance
- `Significant` (bool): `True` if p_value < 0.05 → multimodal
- `ModalLow`, `ModalHigh` (float): Bounds of the modal region

```python
dip = ds["dip_results"]
hysteresis_row = dip.iloc[2]   # Hysteresis domain
is_bimodal = hysteresis_row["Significant"]
p_val      = hysteresis_row["p_value"]
```

---

### Average Hysteresis Loop Trajectory

#### `avgHystLoopTraj` (pd.DataFrame)

Columns: `Pressure_mean`, `Pressure_std`, `Contraction_mean`, `Contraction_std`

Mean and std of pressure/contraction trajectories resampled across all cycles. Each row corresponds to one sample position in the normalized cycle.

```python
traj = ds["avgHystLoopTraj"]

import matplotlib.pyplot as plt
plt.plot(traj["Pressure_mean"], traj["Contraction_mean"], 'b-', label="Mean")
plt.fill_betweenx(
    traj["Contraction_mean"],
    traj["Pressure_mean"] - traj["Pressure_std"],
    traj["Pressure_mean"] + traj["Pressure_std"],
    alpha=0.3
)
plt.xlabel("Pressure"); plt.ylabel("Contraction"); plt.legend(); plt.show()
```

### User Metrics Keys (when `new_metrics: true`)

The following keys are added by `user_metrics.py` when enabled in `.metadata.yaml`. They do not appear for cycle-based datasets or datasets without `new_metrics: true`.

#### `user_activeDat` (pd.DataFrame)

`activeDat` columns plus any columns added in `compute_user_metrics()`, joined back via `Cycle`. The provided example adds:

- `Contraction_Range`: stroke length per cycle (max minus min contraction)

## Common Access Examples

### Example 1: Compile Key Metrics for One Dataset

```python
import pickle

with open("analysis_results/all_results.pkl", "rb") as f:
    io_results = pickle.load(f)

datasets = [k for k in io_results if not k.startswith("_")]
ds = io_results[datasets[0]]

summary = {
    "source":               ds["_source"],
    "loop_mean":            ds["LoopMean"],
    "loop_std":             ds["LoopSTD"],
    "norm_loop_value":      ds["NormLoopValue"],
    "centroid_pressure":    ds["CentroidDrift_summary"][0]["mean"],
    "centroid_contraction": ds["CentroidDrift_summary"][1]["mean"],
    "ellipse_area":         ds["ellipse_result"]["area"],
    "eccentricity":         ds["ellipse_result"]["eccentricity"],
    "hysteresis_corr":      ds["cyc2cyc_results"].iloc[2]["MeanCorr"],
    "is_bimodal":           ds["dip_results"].iloc[2]["Significant"],
}
print(summary)
```

### Example 2: Compare All Datasets

### Example 4: Cycle-to-Cycle Consistency Summary

```python
import pickle

with open("analysis_results/all_results.pkl", "rb") as f:
    io_results = pickle.load(f)

ds = io_results[list(io_results.keys())[0]]

    print(f"  Bimodal: {dip.iloc[i]['Significant']}  "
          f"(dip={dip.iloc[i]['DipStat']:.4f}, p={dip.iloc[i]['p_value']:.3f})")
```

## Parameter Reference

Default parameters used by `run_analysis.py` when `.metadata.yaml` does not override them:

```python
pam_metric_analysis_combined(
    data_source,         # Path to CSV folder
    step_count=1,        # Cycle stride for snapshot selection (every N cycles)
    step_analysis=1,     # Cycle stride for metric analysis
    firstcyc=1,          # First cycle to include
    lastcyc=120,         # Last cycle to include (upper bound; actual max used if fewer)
    active_len=6,        # Active window duration in seconds
    delta_p=3.44738,     # Pressure rise threshold above baseline (psi)
    backup_time=0.5,     # Pre-rise lead time (s)
    npts=200,            # Interpolation points for cycle-to-cycle correlation
    min_overlap=0.90,    # Minimum domain overlap for hysteresis correlation
)
```

Per-folder `.metadata.yaml` overrides `active_len`, `delta_p`, `backup_time`, `analysis_mode`, and `lastcyc`. All other parameters apply globally.

## Notes & Caveats

1. **Outlier interpolation**: Centroid outliers detected by Mahalanobis distance are linearly interpolated (filled) before computing ellipse and regression. Raw outlier indices are preserved in `CentroidDrift_outlier`.

2. **NaN values**: May appear when a cycle has insufficient data (< 3 points) or a metric is undefined for the dataset. Use `np.nanmean()` / `np.nanstd()` when aggregating.

3. **sklearn model serialization**: `mdl_fit` is a scikit-learn `LinearRegression` object. Pickle portability depends on scikit-learn version compatibility.

4. **Python vs MATLAB differences**:
   - MATLAB `ellipse_result` struct includes debugging fields (`cov`, `centroid_pressure`, `centroid_pot`); Python omits these as redundant
   - MATLAB `fitlm()` vs Python `sklearn.linear_model.LinearRegression`: equivalent results, different APIs
   - All numerical results should match between implementations; use the released dataset for verification

5. **Memory**: Large datasets produce large pickle files. Filter by `firstcyc`/`lastcyc` or use `step_analysis > 1` to reduce size when working with thousands of cycles.
